Elevor360D Image Compressor Pro V1

Upload all files and folders to your GitHub Pages repository, preserving advertising/images/.
Open the GitHub Pages link in Chrome or Edge. Use Install App or your browser install menu.

Features: batch JPG/PNG/WebP import, instant original previews, output quality, optional downscaling, output sizes and percentage change, individual downloads and ZIP.
Images are processed on your device. WebP/JPG compression is lossy. PNG is lossless and may produce larger files. The app does not preserve original EXIF metadata.

Advert settings: edit advertising/adverts.json and place advert pictures in advertising/images/. A built-in sample advert appears if settings cannot load when opening locally.

The advertising image and logo are reused from the working Image Format Converter Pro V1.5 package.
